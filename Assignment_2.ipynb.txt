        "\n",
        "1. Modularity – Functions break down complex problems into smaller, manageable parts, making code easier to understand and maintain.\n",
        "\n",
        "\n",
        "2. Code Reusability – A function can be written once and used multiple times, reducing redundancy and saving time.\n",
        "\n",
        "\n",
        "3. Readability & Maintainability – Well-named functions make code more readable and easier to debug or modify.\n",
        "\n",
        "\n",
        "4. Abstraction – They allow programmers to focus on high-level logic without worrying about low-level details every time.\n",

        "\n",

        "*Abstract Methods*\n",
        "1. *Declaration*: Abstract methods are declared using the `@abstractmethod` decorator from the `abc` module.\n",
        "2. *Implementation*: Abstract methods do not have an implementation in the abstract class.\n",
        "3. *Subclass Implementation*: Abstract methods must be implemented by any non-abstract subclass.\n",
        "4. *Instantiation*: A class with abstract methods cannot be instantiated.\n",

        "1. *Declaration*: Regular methods are declared without any special decorator.\n",
        "2. *Implementation*: Regular methods have an implementation in the class.\n",
        "3. *Subclass Implementation*: Regular methods can be overridden by subclasses, but it's not required.\n",

This is achieved by restricting direct access to an object's attributes and methods and providing controlled access through public methods. Here are the main reasons why encapsulation is essential in OOP:\n",
        "\n",
        "1. Data Protection and Security\n",
        "\n",
        "Encapsulation protects an object's internal state by making attributes private. External code cannot modify these attributes directly, reducing the risk of accidental or unauthorized changes.\n",

        "\n",
        "\n",
        "2. Improved Code Maintainability\n",
        "\n",
        "Encapsulation allows developers to change the internal implementation of a class without affecting external code that uses the class. This ensures that changes can be made more easily and with less risk of breaking existing functionality.\n",
        "\n",
        "\n",
        "3. Encourages Modularity\n",
        "\n",
        "By keeping an object's implementation details separate from its interface, encapsulation promotes modular design. Each class can focus on a specific functionality, making the system easier to understand and manage.\n",
        "\n",
        "\n",
        "4. Enhanced Flexibility\n",
        "\n",
        "Through encapsulation, you can enforce rules and constraints on how data is accessed or modified (e.g., validation logic in setter methods). This ensures the object remains in a valid state throughout its lifecycle."
